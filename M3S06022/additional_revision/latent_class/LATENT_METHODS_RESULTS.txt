Formal Gaussian latent class linear mixed models were fitted in R 4.6.1 using lcmm 2.2.2 (hlme), with SIC as the longitudinal response and time coded 0, 1 and 2 for W1-W3. Each class had an intercept and linear time slope; a subject random intercept and residual variance were shared across classes. Class probabilities had intercepts only. Candidate K=1-4 models were evaluated without loading mortality outcomes. Each K>1 used 40 seeded random starts from the one-class model (up to 30 iterations); the six highest short-run likelihoods were refitted to at most 1,000 iterations. Parameter, likelihood and derivative convergence tolerances were all 1e-5; only full convergence (conv=1) was accepted for model comparison. BIC used subjects as the sample size. Posterior assignments used maximum probability; neutral labels were sorted by fitted W1 level. The complete-three-window subset repeated the same specification and search. Frozen derivation models were applied to observed eICU SIC values for descriptive posterior allocation, not mortality-prediction validation.

SIC is an ordered, bounded 0-6 score, whereas hlme uses a Gaussian continuous approximation. Classes can approximate distributional non-normality rather than distinct biological populations. Three windows support only the specified short linear trajectories. The full observed-data analysis included 1,341 MIMIC admissions with one observed SIC value (12.4%); these inform level but not individual change. Observed-value likelihood requires an unverified missing-at-random assumption. The complete-case analysis selects a different observation population and cannot eliminate informative missingness. eICU posterior allocation is descriptive and includes repeated admissions from some persons. This univariate SIC model differs from the original multivariable K-means feature space and does not reproduce or validate its K4 labels. A BIC minimum at K4 means best among K1-K4 candidates, not proof that four classes are globally optimal, biologically real or treatment-relevant. All patient-level records and fitted model parameters remain local and restricted; this public export contains only source code and aggregate reporting.
